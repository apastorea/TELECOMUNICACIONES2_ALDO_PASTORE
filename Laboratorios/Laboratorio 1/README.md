# Laboratorio 1 — Instalación, Hello World y LED temporizados

**Plataforma:** TelosB (MSP430F1611)  
**Sistema operativo:** RIOT OS 2026.04

## Descripción

Se configuró el entorno de desarrollo utilizando WSL2, Ubuntu y MSP430-GCC; se compiló y programó la plataforma TelosB mediante GoodFET BSL. La aplicación desarrollada muestra mensajes por UART, ofrece una shell con los comandos `help` e `info` y controla los LED0, LED1 y LED2 mediante un temporizador periódico configurado a 500 ms por cambio.

El código fuente, los informes y las capturas de compilación, flasheo y terminal están incluidos en este directorio.
