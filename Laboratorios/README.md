# Laboratorios — Telecomunicaciones 2

Esta carpeta reúne las prácticas desarrolladas durante la asignatura **Telecomunicaciones 2** de Ingeniería Electrónica. Se incluyen programas, archivos de configuración, informes y evidencias de ejecución.

## Prácticas

### [Laboratorio 1 — RIOT OS y TelosB](./Laboratorio%201/)
Instalación y puesta en marcha del entorno WSL2 y la herramienta de compilación MSP430; programación de TelosB con RIOT OS, ejecución de *Hello World*, pruebas de consola serie y secuencia periódica de los tres LED.

### [Laboratorio 2](./Laboratorio%202/)
Material y entregables correspondientes a la segunda práctica. La descripción técnica específica se documentará a partir de sus archivos originales.

### [Laboratorio 3 — Comunicación multisalto](./Laboratorio%203/)
Implementación de una red IEEE 802.15.4 de tres nodos TelosB con RIOT OS: SENSOR → RELAY → SINK. Registro y análisis de números de secuencia, RSSI, LQI, PRR, reenvío, CCA y descarte por TTL agotado.
